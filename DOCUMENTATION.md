# Tuggi Drive B2B Website - Complete Documentation

## Project Overview

**Tuggi Drive** is a B2B travel technology company that provides AI-powered cultural storytelling solutions for transportation companies. Their main product transforms routine rides into engaging cultural experiences through location-based narration and multilingual support.

## Technical Architecture

- **Framework**: React with TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Routing**: Custom SPA routing system
- **Languages**: Multilingual support (English, Portuguese, Spanish)
- **Analytics**: Google Analytics 4 integration
- **SEO**: Dynamic meta tags with useSEO hook

## Navigation Structure

The website uses a single-page application (SPA) architecture with custom routing that supports multilingual URLs:

- **Home**: `/` or `/en/` (default)
- **Purpose**: `/en/purpose`, `/pt/purpose`, `/es/purpose`
- **Story & Team**: `/en/story`, `/pt/nossa-historia`, `/es/nuestra-historia`
- **Products**: `/en/products`, `/pt/produtos`, `/es/productos`
- **Business Benefits**: `/en/benefits`, `/pt/beneficios`, `/es/beneficios`
- **Contact**: `/en/contact`, `/pt/contato`, `/es/contacto`
- **Privacy Policy**: `/en/privacy-policy`, `/pt/politica-de-privacidade`, `/es/politica-de-privacidad`
- **Cookie Policy**: `/en/cookie-policy`, `/pt/politica-de-cookies`, `/es/politica-de-cookies`
